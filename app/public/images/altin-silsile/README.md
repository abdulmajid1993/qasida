# Bilder — Altin Silsile

Hier kommen die Bilderordner für die 39 Meister der Altin Silsile rein.

## So lädst du sie auf GitHub hoch

1. Öffne diesen Ordner (`app/public/images/altin-silsile/`) auf GitHub.com.
2. Klick auf **Add file → Upload files**.
3. Ziehe deine lokalen Bilderordner (z. B. `01_Seyyidina Hazreti Muhammed (S.A.V.)`,
   `02-Seyyidina Ebû Bekr-î Sıddık-ra`, …) per Drag & Drop in das Upload-Fenster.
   Chrome/Edge übernehmen dabei automatisch die Ordnerstruktur.
4. Unten einen Commit-Kommentar eintragen und direkt in den Branch **osmanbey**
   committen (nicht in `main`).

Am einfachsten ist es, die Ordnernamen wie in deiner lokalen Struktur zu behalten
(z. B. mit der gleichen Nummer wie in `AltinSilsileBook.jsx`, Feld `order`), dann
kann ich die Bilder danach leicht den richtigen Personen zuordnen.

Sobald die Bilder hochgeladen sind, sag mir kurz Bescheid — ich trage dann die
Pfade in `app/src/AltinSilsileBook.jsx` (Feld `image`) für jede Person ein.
